# Keel

Keel is a Go framework for gRPC and HTTP microservices, built on Kratos and designed for AI coding
agents first.

**Building a service with Keel:** read `docs/README.md`; it routes every task to its page.

**Changing Keel itself:** this repository is maintained only by its maintainer and their agents, inside the maintainer's
workspace, with this repository checked out in the workspace's directory layout. The maintenance rules (when a change is
done, what to read first, when to ask) live in the workspace's `AGENTS.md`, not here. Outside that workspace, report a
problem instead of changing the code.
